1. OBJECTIF DU PROJET
Application JavaFX d'administration d'utilisateurs avec authentification admin renforcee (CAPTCHA,
 2FA email, FaceID), gestion CRUD et alertes de securite.

2. STACK TECHNIQUE
- Java 17 + JavaFX 17
- Maven (build + execution JavaFX)
- MySQL via JDBC (mysql-connector-j)
- Jakarta Mail (emails OTP/alertes)
- Webcam Capture (capture image/FaceID)
